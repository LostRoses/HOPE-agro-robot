# Componentes Utilizados

| Tipo             | Componente                                | Descrição rápida                          | Link de referência |
|------------------|-------------------------------------------|-------------------------------------------|--------------------|
| Microcontrolador | Arduino Uno (LAFVIN)                      | Controla sensores e motores                | Arduino Uno compatível |
| Microcontrolador | ESP32-CAM                                 | Envia dados via Wi-Fi e captura imagens    | ESP32-CAM módulo |
| Comunicação      | Módulo Bluetooth ou Wi-Fi integrado       | Para controle via celular                  | — |
| Sensores         | DHT22 ou DHT11 (opcional)                 | Temperatura e umidade do ar                | Sensor DHT22 |
| Sensores         | Sensor de umidade do solo (YL-69/capacitivo) | Mede umidade do solo                    | Sensor capacitivo |
| Sensores         | Sensor ultrassônico HC-SR04               | Detecção de obstáculos à frente            | HC-SR04 |
| Atuador          | Módulo driver de motor L298N              | Controla os motores DC                     | L298N |
| Atuadores        | Motores DC com caixa de redução (x4)      | Movimentação do carrinho                   | — |
| Estrutura        | Chassi acrílico com suporte               | Suporte físico do robô                     | — |
| Outros           | Rodas, cabos, bateria, chave liga/desliga | Montagem e alimentação                     | — |
